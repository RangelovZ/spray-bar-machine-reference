# Diagrams

This folder contains visual references for the main architectural and functional concepts used in the project.

* [Application Architecture](application_architecture.md) – application composition, execution relationship, and shared data ownership.
* [Automatic Operation](automatic_operation.md) – normal automatic production flow and controlled stop sequence.
* [Homing Responsibility](homing_responsibility.md) – responsibility split between the Sequence Manager and Axis Module during homing.

The diagrams are maintained as Mermaid diagrams so they remain version-controlled and easy to update together with the documentation.
